## 一、根目录总览

```
CipherWS\
├── frontend\          # 前端工程（Vue 3 + Vite 单页应用）
├── server\            # 后端工程（Java / Maven，模块化）
├── deploy\            # 部署相关文件（当前为空，预留）
├── docs\              # 项目文档（接口文档、结构说明等）
├── .git\              # Git 版本库
├── .gitignore         # Git 忽略规则（当前为空文件）
└── README.md          # 项目简介
```

| 名称         | 类型 | 职责                                  |
| ------------ | ---- | ------------------------------------- |
| `frontend\`  | 目录 | 前端主站，负责页面渲染与接口调用      |
| `server\`    | 目录 | 后端服务，提供 REST 接口与业务逻辑    |
| `deploy\`    | 目录 | 部署脚本 / 配置的预留位置（暂无内容） |
| `docs\`      | 目录 | 项目文档集中存放处                    |
| `.git\`      | 目录 | Git 版本库元数据                      |
| `.gitignore` | 文件 | 仓库忽略规则                          |
| `README.md`  | 文件 | 项目说明（`# CipherWS`）              |
