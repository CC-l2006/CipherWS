# 接口文档

## 基础信息

基础地址: `http://192.168.8.100:8080`

## 通用返回格式

```json
{
    "success": true,          // 响应是否成功，bool类型: 
    "errMessage": "",		//错误消息
    "data": {},          // 返回数据
    "total":            //返回值为数组时携带，数组的总数
}
```

## Say模块

### 获取名人名言

**接口说明:** 通过id获取名人名言

**请求地址:** `/say/saying`

**请求方式:** `GET`

**请求参数:**

| 参数名 | 类型 | 必填 | 说明       |
| ------ | ---- | ---- | ---------- |
| id     | int  | 是   | 名人名言ID |

**返回数据:**

```json
{
    "success": true,
    "errorMsg": null,
    "data": {
        "id": "名人名言ID",
        "saying": "名人名言",
        "person": "作者"
    },
    "total": null
}
```
