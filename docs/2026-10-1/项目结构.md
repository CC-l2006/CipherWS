# CipherWS 项目结构（根目录）

> 说明：本文只描述**根目录**这一层的结构与职责，每个目录列出直接子项，方便快速建立全局认知。
> 统计时间：2026-10-01

## 一、根目录总览

```
CipherWS\
├── frontend\          # 前端工程（Vue 3 + Vite 单页应用）
├── server\            # 后端工程（Java / Maven，模块化）
├── deploy\            # 部署相关文件（当前为空，预留）
├── docs\              # 项目文档（接口文档、结构说明等）
├── .git\              # Git 版本库
├── .gitignore         # Git 忽略规则（当前为空文件）
└── README.md          # 项目简介
```

| 名称 | 类型 | 职责 |
| --- | --- | --- |
| `frontend\` | 目录 | 前端主站，负责页面渲染与接口调用 |
| `server\` | 目录 | 后端服务，提供 REST 接口与业务逻辑 |
| `deploy\` | 目录 | 部署脚本 / 配置的预留位置（暂无内容） |
| `docs\` | 目录 | 项目文档集中存放处 |
| `.git\` | 目录 | Git 版本库元数据 |
| `.gitignore` | 文件 | 仓库忽略规则 |
| `README.md` | 文件 | 项目说明（`# CipherWS` / 个人建站） |

## 二、各目录直接子项

### 1. frontend\ —— 前端工程

```
frontend\
├── public\                # 静态资源（不经打包直接拷贝）
├── src\                   # 源码目录
│   ├── api\               # 接口封装（对应后端 REST 接口）
│   ├── assets\            # 图片、样式等资源
│   ├── components\        # 通用组件
│   ├── utils\             # 工具函数
│   ├── App.vue            # 根组件
│   └── main.js            # 应用入口
├── dist\                  # 构建产物
├── .claude\               # 本地 AI 辅助配置
├── .gitignore
├── config.js              # 前端运行配置
├── index.html             # 页面模板入口
├── package.json           # 依赖与脚本
├── package-lock.json      # 依赖锁定
└── vite.config.js         # Vite 构建配置
```

- 技术栈：Vue 3 + Vite
- 关键入口：`index.html` → `src/main.js` → `src/App.vue`
- 接口层统一收敛在 `src/api/`，与 `docs/接口文档.md` 对应

### 2. server\ —— 后端工程

```
server\
├── CipherWS-server\       # 后端主体模块（Maven 工程）
└── .idea\                 # IDE 工程配置
```

`CipherWS-server\` 内部：

```
CipherWS-server\
├── src\                   # Java 源码与资源
├── target\                # 编译输出
├── .mvn\                  # Maven Wrapper 配置
├── .idea\
├── pom.xml                # Maven 依赖与构建配置
├── mvnw                   # Maven Wrapper（Linux / macOS）
├── mvnw.cmd               # Maven Wrapper（Windows）
├── .gitattributes
└── .gitignore
```

- 技术栈：Java + Maven
- 构建方式：`mvnw.cmd` 或 `mvn clean package`
- 运行后提供 `docs/接口文档.md` 中描述的基础地址（如 `http://192.168.8.100:8080`）

### 3. deploy\ —— 部署目录

```
deploy\
└── （空）
```

目前为预留目录，用于后续放置部署脚本、Nginx 配置或容器编排文件。

### 4. docs\ —— 文档目录

```
docs\
├── 接口文档.md            # 后端接口说明（基础信息、通用返回格式、各模块接口）
└── 2026-10-1\
    ├── 前端项目结构.md     # 前端目录结构说明（规划结构）
    └── 项目结构.md         # 本文档（根目录结构说明）
```

- `接口文档.md`：定义通用返回格式 `{ success, errMessage, data, total }` 及 `Say` 等模块接口
- `2026-10-1\`：按日期归档的结构类文档

## 三、整体关系

```
        docs\  ← 文档说明（接口 / 结构）
          ▲
          │ 描述
   frontend\ ──HTTP──▶ server\ ──▶ 数据库 / 外部服务
   (Vue SPA)           (Java API)
          │
          ▼
       deploy\  ← 前端静态资源与后端服务的部署入口
```

- `frontend\` 通过 `src/api/` 调用 `server\` 暴露的接口
- `docs\` 为两者提供契约与结构说明，接口变更应先更新 `docs/接口文档.md`
- `deploy\` 负责把 `frontend\dist\` 与 `server\CipherWS-server\target\` 的产物发布上线
