# 接口文档

> 说明：后端已微服务化，接口由 `cipherws-say-service` 提供，对外统一经**网关**访问。
> 基础地址（网关）：`http://<网关主机>:8080`，例如 `GET http://127.0.0.1:8080/say/saying?id=1`。
> 另有 OpenFeign 演示接口 `GET /portal/say/{id}`（由 `cipherws-portal-service` 经 OpenFeign 调用 say 服务），返回结构与 `/say/saying` 一致。
> 详见 [../docs/微服务架构.md](../docs/微服务架构.md)。

## say

### 接口说明

根据文本id获取文本

## 请求

**请求路径：/say/saying**

**请求方式：GET**

### 请求参数

| 参数名称 | 参数类型 | 是否必须 | 参数说明         |
| -------- | -------- | -------- | ---------------- |
| id       | int      | 是       | 需要响应的文本id |

### 响应格式

```json
{
	"success":true,
	"errorMsg":null,
	"data":"文本",
	"total":null
}
```

## audio音频流播放

### 接口说明

根据音频名称获取音频流（支持 HTTP `Range` 分段请求）

### 请求

**请求路径：/audio/stream**

**请求方式：GET**

### 请求头

| 请求头   | 必填 | 说明                                                         |
| -------- | ---- | ------------------------------------------------------------ |
| `Range`  | 否   | 范围请求，如 `bytes=0-`、`bytes=1024-2047`。拖动播放进度条时由浏览器 / `<audio>` 自动携带 |
| `Origin` | 否   | 跨域请求时由浏览器自动携带                                   |

### 请求参数

| 参数名称 | 参数类型 | 是否必须 | 参数说明                           |
| -------- | -------- | -------- | ---------------------------------- |
| audio    | string   | 是       | 音频文件名（含扩展名），需 URL 编码 |

### 响应头

| 响应头                | 示例                                                         | 说明                                                         |
| --------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `Content-Type`        | `audio/mpeg`                                                 | 按文件扩展名推断，见下方对照表；无法识别时为 `application/octet-stream` |
| `Content-Length`      | `8451200`                                                    | 本次响应体的字节数（`206` 时是该片段的长度）                 |
| `Content-Disposition` | `inline; filename="=?UTF-8?Q?...?="; filename*=UTF-8''%E5%91%A8...` | `inline` 表示浏览器内联播放；含中文等非 ASCII 字符时同时给出 RFC 2047 编码的 `filename` 与 RFC 5987 编码的 `filename*` |
| `Accept-Ranges`       | `bytes`                                                      | 由 Spring MVC 自动添加，表示支持范围请求                     |
| `Content-Range`       | `bytes 0-1023/8451200`                                       | 仅 `206` / `416` 出现；`416` 时为 `bytes */<总长度>`         |



常见扩展名与 `Content-Type` 的对照：

| 扩展名 | `Content-Type` |
| --- | --- |
| `.mp3` | `audio/mpeg` |
| `.ogg` / `.oga` / `.opus` | `audio/ogg` |
| `.m4a` / `.mp4a` | `audio/mp4` |
| `.flac` | `audio/x-flac` |
| `.wav` | `audio/x-wav` |
| `.aac` | `audio/x-aac` |
| 其他 | `application/octet-stream` |

### 响应体

**完整返回 `200 OK`**

不带 `Range` 请求头时返回整个文件：

```http
HTTP/1.1 200 OK
Content-Type: audio/mpeg
Content-Length: 8451200
Content-Disposition: inline; filename="=?UTF-8?Q?=E5=91=A8=E6=9D=B0=E4=BC=A6_-_=E6=99=B4=E5=A4=A9.mp3?="; filename*=UTF-8''%E5%91%A8%E6%9D%B0%E4%BC%A6%20-%20%E6%99%B4%E5%A4%A9.mp3
Accept-Ranges: bytes

<音频二进制数据>
```

**分段返回 `206 Partial Content`**

带 `Range` 请求头时返回对应区间：

```http
HTTP/1.1 206 Partial Content
Content-Type: audio/mpeg
Content-Length: 1024
Content-Range: bytes 0-1023/8451200
Accept-Ranges: bytes

<该区间的音频二进制数据>
```

`Content-Range` 格式为 `bytes <起始>-<结束>/<总长度>`，客户端据此拼接数据、跳转播放位置。`206` 响应中的 `Content-Type`、`Content-Disposition`、`Accept-Ranges` 与完整返回时一致，仅 `Content-Length` 变为片段长度。

### 状态码

| 状态码 | 触发场景 | 响应体类型 |
| --- | --- | --- |
| `200 OK` | 未带 `Range`，返回完整音频 | 音频二进制流 |
| `206 Partial Content` | 请求头带合法 `Range`，返回对应片段 | 音频二进制片段 |
| `400 Bad Request` | 缺少 `audio` 参数 | JSON（Spring Boot 默认错误页） |
| `404 Not Found` | 音频文件不存在，或 `audio` 解析后越出音乐根目录 | JSON（Spring Boot 默认错误页） |
| `405 Method Not Allowed` | 使用非 `GET` 方法请求 | JSON（Spring Boot 默认错误页） |
| `416 Requested Range Not Satisfiable` | `Range` 无法满足（如起始位置超过文件长度） | 由 Spring MVC 返回，响应头带 `Content-Range: bytes */<总长度>` |
| `500 Internal Server Error` | 服务端异常 | JSON（Spring Boot 默认错误页） |

### 错误响应体

非 2xx 响应由 Spring Boot 默认错误处理返回，格式固定为：

```json
{
  "timestamp": "2026-10-05T02:39:06.123+00:00",
  "status": 404,
  "error": "Not Found",
  "path": "/audio/stream"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `timestamp` | string | 出错时间，ISO-8601（`java.util.Date` 序列化，默认 UTC） |
| `status` | number | HTTP 状态码 |
| `error` | string | 状态码对应的原因短语 |
| `path` | string | 请求路径 |
